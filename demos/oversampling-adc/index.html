FIELD NOTES / 01

Precision from repetition.

The analog input is compared with the previous DAC output. An integrator accumulates the difference, and a quantizer makes a fast, coarse decision. Negative feedback shapes quantization error toward higher frequencies. A digital low-pass filter removes out-of-band content before samples are discarded.

What is being simulated?

This is a discrete-time, first-order behavioral loop: e[n] = x[n] − d[n−1], s[n] = λs[n−1] + k·e[n], y[n] = Q(s[n]). The feedback DAC maps codes to ±Vref. The digital filter is a causal, normalized windowed-sinc FIR, followed by decimation. Switch to a moving average to compare its weaker stopband rejection.

OSR = fₛ / (2B) for the configured signal bandwidth B. Decimation factor M is independently adjustable; output rate is fₛ/M. Signal parameters are expressed in volts and hertz. Plots show actual computed samples. The spectrum uses a Hann-windowed, 4096-point FFT, normalized to Vref peak (dBFS); it is a visualization, not a precision SNR measurement.

Try this

Select DC → pulse density, then move the input offset. With a symmetric ideal 1-bit DAC, the fraction of high bits approaches (Vin/Vref + 1)/2. Try Loop overload to see what happens when input range exceeds the feedback range.

At 1× speed, 0.05 seconds of simulated time pass per real second. Animation packets indicate direction; their speed and count do not represent physical signal propagation or every sample. Filter delay is visible in the output. The FIR uses a practical finite number of taps, so attenuation is finite. Changing parameters restarts the simulation capture.
