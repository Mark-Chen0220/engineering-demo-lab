WHY IT WORKS / 標準差的縮放
σ平均 = σ原始 / √N
20 log₁₀(σ平均 / σ原始) = −10 log₁₀ N

前提：各點獨立且變異數相同；此處平均的是零均值隨機誤差。固定偏差不會被平均消除。

進階實驗：如果雜訊彼此相關？

ρ = 0：獨立。ρ = 1：同組各點完全相同，平均不再降低標準差。模型只考慮 0 ≤ ρ ≤ 1。

01 /

平均的是正負誤差

x̄ = (x₁ + ⋯ + xN) / N
同組點的橫向位置取中心；點數從 N 個變成 1 個。

02 /

變異數 ÷N，標準差 ÷√N

獨立雜訊的變異數可以相加。除以 N 做平均後，標準差依 1/√N 下降。

03 /

「掉 3 dB」是每加倍平均點數

N = 2 → −3.01 dB；N = 4 → −6.02 dB。
標準差用 20 log₁₀；變異數／功率用 10 log₁₀，得到相同的 dB 變化。非重疊平均也會降低輸出取樣率。
